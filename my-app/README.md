# Practical 1 - My App

This is the first React practice project in the `react-practice` folder. It is a very small CRA-based starter used for setup and basic component rendering practice.

## Overview

The app currently renders a single root component and acts as a base project for experimenting with React structure, imports, and component exports.
This project was created using Create React App.

## Ways To Create A React App

There are multiple starter options you can use to create a React project. This practical is based on Create React App, but you can also use Vite or a custom starter like `set-react-app`.

### 1. Create React App

```bash
npx create-react-app my-app
cd my-app
npm start
```

### 2. Vite

```bash
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev
```

### 3. Set React App

```bash
npx set-react-app my-app
cd my-app
npm start
```

## Features

- Minimal Create React App setup
- Single `App` component entry point
- Ready for incremental React practice and component experiments

## Available Scripts

In the project directory, run:

- `npm start` - start the development server on `http://localhost:3000`
- `npm test` - launch the test runner
- `npm run build` - create a production build in `build/`
- `npm run eject` - expose the CRA build configuration

## Notes

This project is intentionally lightweight and can be used as a base for future exercises.
